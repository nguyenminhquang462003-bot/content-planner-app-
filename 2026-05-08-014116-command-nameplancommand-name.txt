     Kế hoạch xây dựng Content Planner App

     Context

     Bài tập xây dựng full-stack web app để tổng hợp, theo dõi và phân tích hiệu
      quả nội dung đa kênh. Người dùng non-tech, cần giải thích đơn giản, làm
     từng bước nhỏ và dừng lại để test sau mỗi bước.

     Tech stack: Next.js 16 App Router + TypeScript + Tailwind CSS v4 + Supabase

     ---
     Các kênh được hỗ trợ

     ┌──────────────────┬────────────────────────────────┐
     │       Kênh       │       Loại nhập dữ liệu        │
     ├──────────────────┼────────────────────────────────┤
     │ Facebook Fanpage │ Tự động qua Facebook Graph API │
     ├──────────────────┼────────────────────────────────┤
     │ Facebook Group   │ Nhập tay (manual)              │
     ├──────────────────┼────────────────────────────────┤
     │ Substack         │ Nhập tay (manual)              │
     └──────────────────┴────────────────────────────────┘

     ---
     Tính năng dashboard

     1. Tổng quan (Overview) — KPI cards + biểu đồ xu hướng
     2. Quản lý bài đăng — Danh sách, thêm/sửa/xóa bài
     3. Phân tích hiệu quả — So sánh kênh, loại nội dung tốt nhất
     4. Tuyến nội dung (Kanban) — Ý tưởng → Bản nháp → Chờ đăng → Đã đăng
     5. Lịch nội dung — Xem bài theo ngày/tháng
     6. Cài đặt kênh — Kết nối Facebook API, quản lý kênh

     ---
     Database Schema (Supabase)

     -- Bảng kênh
     CREATE TABLE channels (
       id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
       user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
       name TEXT NOT NULL,
       type TEXT NOT NULL CHECK (type IN ('fanpage', 'group', 'substack')),
       fb_page_id TEXT,
       fb_access_token TEXT,
       created_at TIMESTAMPTZ DEFAULT NOW()
     );

     -- Bảng bài đăng
     CREATE TABLE posts (
       id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
       user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
       channel_id UUID REFERENCES channels(id) ON DELETE CASCADE,
       title TEXT,
       content_type TEXT CHECK (content_type IN ('video', 'image', 'text',
     'article')),
       published_at TIMESTAMPTZ,
       views INTEGER DEFAULT 0,
       likes INTEGER DEFAULT 0,
       comments INTEGER DEFAULT 0,
       shares INTEGER DEFAULT 0,
       reach INTEGER DEFAULT 0,
       status TEXT DEFAULT 'published' CHECK (status IN ('draft', 'scheduled',
     'published')),
       external_id TEXT,
       url TEXT,
       created_at TIMESTAMPTZ DEFAULT NOW()
     );

     -- Bảng tuyến nội dung (Kanban)
     CREATE TABLE pipeline_items (
       id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
       user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
       channel_id UUID REFERENCES channels(id) ON DELETE SET NULL,
       title TEXT NOT NULL,
       description TEXT,
       stage TEXT DEFAULT 'idea' CHECK (stage IN ('idea', 'draft', 'review',
     'scheduled', 'published')),
       planned_date DATE,
       content_type TEXT,
       created_at TIMESTAMPTZ DEFAULT NOW()
     );

     -- Row Level Security: mỗi user chỉ thấy dữ liệu của mình
     ALTER TABLE channels ENABLE ROW LEVEL SECURITY;
     ALTER TABLE posts ENABLE ROW LEVEL SECURITY;
     ALTER TABLE pipeline_items ENABLE ROW LEVEL SECURITY;

     ---
     Lưu ý quan trọng về Next.js 16

     - proxy.ts thay cho middleware.ts — hàm phải tên là proxy (không phải
     middleware)
     - Server Functions (không gọi là Server Actions nữa) — dùng 'use server'
     directive
     - Server Components mặc định — chỉ thêm 'use client' khi cần tương tác
     (click, state, useEffect)

  4. Copy toàn bộ đoạn SQL bên dưới và dán vào ô soạn thảo:

  -- Bảng kênh (channels)
  CREATE TABLE channels (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    name TEXT NOT NULL,
    type TEXT NOT NULL CHECK (type IN ('fanpage', 'group', 'substack')),
    fb_page_id TEXT,
    fb_access_token TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );

  -- Bảng bài đăng (posts)
  CREATE TABLE posts (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    channel_id UUID REFERENCES channels(id) ON DELETE CASCADE,
    title TEXT,
    content_type TEXT CHECK (content_type IN ('video', 'image', 'text',
  'article')),
    published_at TIMESTAMPTZ,
    views INTEGER DEFAULT 0,
    likes INTEGER DEFAULT 0,
    comments INTEGER DEFAULT 0,
    shares INTEGER DEFAULT 0,
    reach INTEGER DEFAULT 0,
    status TEXT DEFAULT 'published' CHECK (status IN ('draft', 'scheduled',
  'published')),
    external_id TEXT,
    url TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );

  -- Bảng tuyến nội dung (pipeline)
  CREATE TABLE pipeline_items (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
    channel_id UUID REFERENCES channels(id) ON DELETE SET NULL,
    title TEXT NOT NULL,
    description TEXT,
    stage TEXT DEFAULT 'idea' CHECK (stage IN ('idea', 'draft', 'review',
  'scheduled', 'published')),
    planned_date DATE,
    content_type TEXT,
    created_at TIMESTAMPTZ DEFAULT NOW()
  );

  -- Bật bảo mật: mỗi user chỉ thấy dữ liệu của mình
  ALTER TABLE channels ENABLE ROW LEVEL SECURITY;
  ALTER TABLE posts ENABLE ROW LEVEL SECURITY;
  ALTER TABLE pipeline_items ENABLE ROW LEVEL SECURITY;

  -- Quy tắc bảo mật cho bảng channels
  CREATE POLICY "Users manage own channels" ON channels
    FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

  -- Quy tắc bảo mật cho bảng posts
  CREATE POLICY "Users manage own posts" ON posts
    FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);

  -- Quy tắc bảo mật cho bảng pipeline_items
  CREATE POLICY "Users manage own pipeline" ON pipeline_items
    FOR ALL USING (auth.uid() = user_id) WITH CHECK (auth.uid() = user_id);
